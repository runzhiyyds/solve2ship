# Solve2Ship v0.10.0 — Engineering preview / 工程预览

## English

Define the outcome. Let solutions compete. Ship the best.

First public source preview of a local goal-to-executable-service system. Supply
samples and a natural-language outcome; STS proposes competing Rules, Prompt,
Hybrid, isolated Python, numeric ML and bounded workflow candidates, executes and
evaluates them, preserves failures/revisions and exports supported local services.

This version adds real model-backed workflow steps, complete multi-call cost
attribution, persistent shared budgets and English/Chinese execution evidence.
Validated locally: 120 Python tests and five Node tests passed. Hosted checks were
unavailable at initial publication; no remote-CI pass is claimed.

Engineering preview: model-backed standalone serving, general agents/harness,
mature optimizers, calibrated evaluation and production hosting remain unfinished.
Synthetic label matches are not verified business accuracy. No model key, private
database, actual user dataset, container image or model runtime is bundled.

Start with README.md, README.zh-CN.md and docs/VISION_COVERAGE.md.

## 简体中文

定义目标。让方案竞争。交付最佳方案。

首次公开一个从目标探索到可执行服务的本机工程原型。提供样本和自然语言期望，系统
自主提出规则、Prompt、混合、隔离 Python、数值机器学习及有界工作流候选，真实执行、
评测并保留失败与版本，导出受支持的本机服务。

本版本新增真实模型工作流步骤、完整多次调用费用归因、持久化共享预算及中英双语
执行证据。已在本机通过 120 项 Python 测试和 5 项前端测试；首发时托管检查无法启动，
不宣称远端 CI 已通过。

这是工程预览版：含模型步骤的独立交付、通用 Agent/Harness、成熟优化器、可信评价与
生产托管仍待实现。合成样本标签一致性不等于真实业务准确率。源码不包含模型密钥、
私有数据库、实际用户数据集、容器镜像或模型运行环境。
