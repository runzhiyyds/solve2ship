# Solve2Ship v0.16.0 — Auditable pricing lifecycle / 可审计价格生命周期

## English

Solve2Ship v0.16.0 replaces the expired daily pricing gate with an explicit,
owner-reviewed lifecycle for new model calls and portable model-backed services.

- `pricing-preview`, `review-pricing` and `pricing-status` provide a local,
  no-network review flow.
- Canonical price documents are hash-addressed and immutable, with endpoint/model
  binding and explicit UTC validity windows of at most seven days.
- Reservations persist the full price snapshot and `version_id`; settlement keeps
  using the original snapshot after later reviews. A gateway binds one operation to
  one active version.
- New model-backed delivery/runtime template v2 includes the reviewed adapter but
  never bundles price documents, credentials or local state. Missing, expired or
  malformed reviews fail closed before provider transport.
- The official DeepSeek pricing page was manually reviewed for the published Flash
  peak ceiling (CNY 2 input / 8 output per million tokens). The source-content hash
  is an operator audit assertion, not an automatic quotation or invoice check.

This is an engineering preview. Provider invoices, semantic quality, production
vaults, tenancy, cloud hosting, automatic renewal and broader provider adapters are
not claimed. See [model configuration](../MODEL_CONFIGURATION.md) for the operator
flow and limits.

## 简体中文

Solve2Ship v0.16.0 将已过期的每日价格门禁替换为面向新模型调用和可移植模型服务的明确价格审核生命周期。

- `pricing-preview`、`review-pricing`、`pricing-status` 提供本地、无网络的价格审核流程。
- 规范价格文件按哈希寻址且不可变，绑定端点/模型，并使用最长七天的明确 UTC 有效期。
- 每次预留都会保存完整价格快照和 `version_id`；后续审核不会改变旧调用的结算价格，单个网关操作不会中途切换版本。
- 新模型交付/运行时模板 v2 包含价格适配器，但不会打包价格文件、凭据或本机状态。缺失、过期或格式错误的审核会在请求服务商前失败关闭。
- 已人工复核官方 DeepSeek 价格页中的 Flash 高峰保守上限（输入每百万 token 2 元、输出 8 元）。来源内容哈希是审计声明，不是自动报价或账单核验。

这是工程预览版本。服务商账单、语义质量、生产凭据保险库、多租户、云托管、自动续期和更多服务商适配器均未声称完成。详见[模型配置说明](../MODEL_CONFIGURATION.md)。
