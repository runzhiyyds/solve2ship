# Solve2Ship v0.15.0 — Container runtime portability / 容器运行环境无关

## English

v0.15.0 removes the local Docker Desktop runtime dependency while keeping Docker
container isolation and the existing image/build boundary. The Engine adapter now
selects local Unix sockets through the standard Docker CLI context contract, with
explicit `DOCKER_CONTEXT`, `DOCKER_HOST` and `DOCKER_CONFIG` precedence. Remote TCP,
SSH and named-pipe endpoints fail closed, and reviewed runtime profiles bind the
selected endpoint fingerprint so context or Engine changes require fresh evidence.

The export verifier discovers the Docker CLI through `PATH` and has no application
bundle fallback. macOS Apple Silicon setup is documented with Colima + Docker Engine
+ Docker CLI/Compose; Linux/cloud setup uses Docker Engine + Compose. The dependency
inventory records Colima 0.10.3, Lima 2.3.0, Docker CLI 29.9.3, Compose 5.7.1 and
Buildx 0.39.0 with licenses and provenance. Runtime binaries, image archives, local
databases, credentials and acceptance evidence are not distributed.

Local acceptance used Colima on macOS Apple Silicon with Docker Engine 29.5.2 and
the reviewed Python image digest. The real isolation verifier passed non-root,
no-mount, network-disabled, read-only-root, seccomp, CPU/memory/process, timeout,
OOM, output-limit and cleanup checks. The current suite passes 183 Python tests
(11 optional schema tests explicitly skipped in the base environment) and seven
Node tests. These checks establish local runtime compatibility and isolation policy;
they do not certify Linux kernel hardening, hostile multi-tenant isolation, cloud
hosting, production serving or business accuracy.

## 简体中文

v0.15.0 在保留 Docker 容器隔离与既有镜像/构建边界的同时，移除本机对 Docker Desktop
运行时的依赖。Engine 适配器按 Docker CLI 标准上下文选择本地 Unix 套接字，支持显式
`DOCKER_CONTEXT`、`DOCKER_HOST` 和 `DOCKER_CONFIG` 优先级。TCP、SSH、命名管道等远程
端点会在请求前失败关闭；验收配置绑定端点指纹，切换上下文或 Engine 后必须重新验收。

导出校验器只从 `PATH` 查找 Docker CLI，不再回退到应用程序路径。Apple Silicon
macOS 的配置说明使用 Colima + Docker Engine + Docker CLI/Compose；Linux/云主机使用
Docker Engine + Compose。依赖清单记录 Colima 0.10.3、Lima 2.3.0、Docker CLI 29.9.3、
Compose 5.7.1 和 Buildx 0.39.0 的许可证与来源。运行时二进制、镜像归档、本机数据库、
凭据和验收证据均不随源码分发。

本机在 Apple Silicon macOS 的 Colima/Docker Engine 29.5.2 上完成真实验收，审阅过的
Python 镜像按不可变摘要运行。非 root、无宿主挂载、禁网、只读根文件系统、seccomp、
CPU/内存/进程限制、超时、OOM、输出限制和清理检查均通过。当前基础环境通过 183 项
Python 测试（11 项可选 schema 测试明确跳过）和 7 项 Node 测试。这些证据证明本机
运行环境兼容与隔离策略，不代表 Linux 内核加固、恶意多租户隔离、云托管、生产服务
或业务准确率已经完成。
